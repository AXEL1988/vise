# 🛡️ VISE Ecuador - Sitio Web Corporativo

Sitio web oficial de VISE Ecuador, empresa líder en soluciones integrales de seguridad.

## 📊 Estadísticas del Proyecto

- **Peso total:** ~60MB (optimizado desde 450MB)
- **Páginas:** 6 (Home, Soluciones, Nosotros, Sectores, Tendencias, Contacto)
- **Imágenes:** 49 optimizadas (-84.9% de peso)
- **Responsive:** ✅ Mobile-first design
- **Performance:** ⚡ Optimizado para velocidad

## 🚀 Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos modernos con Flexbox/Grid
- **JavaScript** - Interactividad y animaciones
- **WebP/JPEG** - Imágenes optimizadas
- **Responsive Design** - Mobile-first approach


## 🛠️ Instalación y Desarrollo

### Requisitos
- Navegador web moderno
- Servidor web local (opcional)

### Instalación
```bash
# Clonar repositorio
git clone https://github.com/TU_USUARIO/vise-ecuador.git

# Navegar al directorio
cd vise-ecuador

# Abrir en navegador
open index.html
```

### Optimización de Imágenes
```bash
# Ejecutar script de optimización
python3 optimize_images.py
```

## 🔧 Mantenimiento

### Actualizar Contenido
1. Editar archivos HTML
2. Modificar estilos en `css/styles.css`
3. Actualizar funcionalidades en `js/script.js`
4. Commit y push a Git

### Optimizar Imágenes
1. Colocar nuevas imágenes en `images/`
2. Ejecutar `python3 optimize_images.py`
3. Reemplazar carpeta `images/` con `images_optimized/`
